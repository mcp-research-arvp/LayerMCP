## What comes from research sources

- The issue text is mechanically extracted from the released
  `<issue_description>` element.
- `trajectory_id`, `instance_id`, repository name, source coordinate, resolved
  flag, exit status, exact function names, serialized argument objects,
  function-call order, call IDs, and tool observations come from the pinned
  dataset.
- The selected rows have `resolved=1` and `exit_status=submit`.

The issue text comes from real GitHub-derived SWE-rebench tasks. The function
trajectories were generated by Qwen3-Coder using OpenHands. They are released
model behaviors, not human-authored gold tool sequences and not uniquely
correct solutions.

## LayerMCP adaptation

- Selection is deterministic: take the first clean submitted row per distinct
  issue in pinned physical order, exclude issue IDs already selected for the
  SWE-agent expansion, and stop after 500 issues.
- The 500 selected source workflows contain 27,481 calls and range from 26 to
  97 calls, so none meets the benchmark's maximum of five calls. The checked-in
  OpenHands benchmark is consequently an empty JSON list.
- Because the benchmark references no OpenHands records, LayerMCP does not
  check in an OpenHands replay fixture or register OpenHands replay tools. The
  pinned source metadata and deterministic importer preserve the selection
  analysis without carrying unused data.
- Assistant prose and explicit `think` calls are omitted so model
  chain-of-thought is not redistributed.
- Each retained function call is matched to its environment observation by
  `tool_call_id`. Trajectories with unmatched nonterminal calls, unsupported
  tools, parallel operational calls, oversized arguments, or
  high-confidence secrets are excluded.
- The importer recognizes four operational families for selection analysis:
  `execute_bash`, `finish`, `task_tracker`, and `str_replace_editor`; none is
  exposed as a runtime replay tool in the current benchmark.
- Observations are bounded to deterministic excerpts plus full-output SHA-256
  values. Exact editor arguments can include generated patch fragments, and
  bounded observations can include test-log excerpts; no complete generated
  workspace or full unbounded evaluation log is copied.
- Terminal `finish` is represented by the empty unavailable-observation
  sentinel when the release ends without a result message.
- No shell command, editor operation, test, task update, or finish action is
  executed.

The workflow query is source issue text. Per-step routing instructions,
prefixed tool names, and replay coordinates are mechanical LayerMCP wrappers.
They are not additional synthetic coding problems.

## License and use boundary

The trajectory release declares CC BY 4.0. The underlying issue and repository
material can remain subject to repository-specific licenses, so this
attribution does not replace review of those terms. Qwen3-Coder is identified
by the source release; users should also review the model terms applicable to
their intended use.

This adaptation documents a deterministic source selection that currently
produces zero benchmark members. It does not mean a process ran, a mutation
occurred, tests passed, or the original issue was autonomously resolved.
